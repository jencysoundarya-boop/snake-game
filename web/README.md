# SNAKE // NEON HUNT (Web Edition)

This folder contains the complete HTML5 / Vanilla JS browser version of the game.

## How it works
This edition uses zero external dependencies or frameworks. It relies solely on:
- **HTML5 Canvas** for rendering the game board, neon gradients, and particle effects.
- **Web Audio API** for generating retro synthesizer sound effects dynamically.
- **LocalStorage** to persist your settings, high scores, and achievements locally in your browser.

## How to run locally
Because it is a purely static website, you do not need Node.js, npm, or any backend server.

Simply double-click `index.html` to open it in your browser, or run a simple local server (if you prefer):
```bash
# Example using Python:
python3 -m http.server 8000
# Then visit http://localhost:8000/web/
```
